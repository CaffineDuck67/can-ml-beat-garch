# Data

This directory is intentionally **not** committed (see the repository
`.gitignore`). All inputs are freely downloadable and are regenerated by the
pipeline, so a fresh clone needs only to run the download step:

```bash
python run_all.py data      # or: make data   (add FORCE=1 / --force to re-download)
```

After downloading, build the leak-safe modelling panel with:

```bash
python run_all.py features   # clean -> targets -> features
```

## Sources

### Prices — Yahoo Finance (via `yfinance`)
| Ticker | Series |
|---|---|
| `^GSPC` | S&P 500 index (daily close) |
| `^VIX`  | CBOE VIX (daily close) |

Saved to `data/raw/SP500.csv.gz`, `data/raw/VIX.csv.gz`.

> **Yahoo Finance terms.** `^GSPC` / `^VIX` daily data are retrieved through the
> [`yfinance`](https://github.com/ranaroussi/yfinance) package from Yahoo
> Finance. Yahoo Finance's terms of service govern this data; it is used here
> for non-commercial research only and is **redistributed in the raw form** —
> the repository ships the download script, not the raw price files. Run the
> download step to reproduce them.

### Macro — FRED (public CSV endpoint, no API key required)
Fetched from `https://fred.stlouisfed.org/graph/fredgraph.csv?id=<SERIES>` with
retry/backoff and a `pandas_datareader` fallback. If a `FRED_API_KEY` is present
in the environment, `fredapi` is used instead.

| FRED ID | Description | Frequency |
|---|---|---|
| `DGS10`      | 10Y Treasury constant-maturity yield (%) | daily |
| `DGS2`       | 2Y Treasury constant-maturity yield (%)  | daily |
| `T10Y2Y`     | 10Y–2Y spread (yield-curve slope, %)      | daily |
| `DFF`        | Effective federal funds rate (%)           | daily |
| `DCOILWTICO` | WTI crude oil spot price ($/barrel)        | daily |
| `BAMLH0A0HYM2` | ICE BofA US High Yield OAS (%) — **truncated by FRED since 2024**, kept only where coverage allows | daily |
| `UNRATE`     | Civilian unemployment rate (%)             | monthly |
| `CPIAUCSL`   | CPI, all urban consumers (index)           | monthly |
| `NFCI`       | Chicago Fed National Financial Conditions Index — full-history financial-stress proxy used in place of the truncated HY spread | weekly |

Monthly and weekly series are **publication-lag shifted before forward-filling**
(see `src/data_clean.py`) so a model only ever sees data that was genuinely
public on date *t*. Note that FRED revises these series; the download uses the
final vintage available at download time (see the README limitations).

## Cache
Downloads are cached in `data/raw/`; existing files are reused unless `--force`
is passed. `data/raw/download_log.json` records row counts, date ranges,
missing values and which source answered for each series.
